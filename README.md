# stock8-7

4개 차트씩 총 5페이지(20칸)를 제공하는 KIS 우선 실시간 주식 대시보드입니다. 종목 설정과 추세선을 서버에 저장합니다.

## 실행

GitHub Codespaces 또는 로컬 환경변수에 아래 값을 설정한 뒤 실행합니다. 실제 키 값은 저장소에 커밋하지 않습니다.

```bash
export KIS_APP_KEY="..."
export KIS_APP_SECRET="..."
export KIS_BASE_URL="https://openapi.koreainvestment.com:9443"
export KIS_WS_URL="ws://ops.koreainvestment.com:21000"
export PORT=8002
npm start
```

KIS 환경변수가 없거나 KIS 응답이 실패하면 기존 공개 시세 데이터로 fallback합니다.

## GitHub Codespaces Secret 설정

KIS 키는 GitHub 저장소 파일에 넣지 말고 Codespaces Secret으로 설정합니다.

1. GitHub에서 `ddubii00/ddubii00-stock8-7` 저장소로 이동합니다.
2. `Settings` → `Secrets and variables` → `Codespaces`로 이동합니다.
3. `New repository secret` 또는 `New secret`을 눌러 아래 이름으로 추가합니다.
   - `KIS_APP_KEY`
   - `KIS_APP_SECRET`
   - `KIS_BASE_URL`
   - `KIS_WS_URL`
4. 값은 각각 KIS에서 발급받은 값을 넣습니다.
5. Codespace를 이미 켜둔 상태라면 재시작하거나 새 Codespace를 만듭니다.
6. Codespace 터미널에서 실행합니다.

```bash
npm start
```

Codespaces Secret은 터미널 환경변수로 자동 주입됩니다. GitHub Actions용 Secret만 만들면 Codespace 터미널에서 보이지 않을 수 있으니, 반드시 Codespaces Secret으로 설정합니다. `KIS_APP_KEY`, `KIS_APP_SECRET`은 Variables가 아니라 Secrets에 넣는 것을 권장합니다.

## 로컬 테스트

로컬에서는 `.env.example`을 참고해서 직접 환경변수를 export한 뒤 실행합니다. `.env` 파일을 만들 경우 `.gitignore`에 의해 커밋되지 않습니다.

## Oracle 서버 실행

Oracle Cloud VM에서는 Node.js 22 이상을 설치한 뒤 저장소를 받아 실행합니다. KIS 키는 저장소에 커밋하지 말고 서버의 `.env` 파일 또는 systemd 환경변수로만 설정합니다.

```bash
git clone https://github.com/ddubii00/ddubii00-stock8-7.git
cd ddubii00-stock8-7
npm install
cp .env.example .env
# .env에 KIS_APP_KEY, KIS_APP_SECRET, PORT를 설정
npm start
```

외부 접속이 필요하면 Oracle 보안 목록/NSG와 서버 방화벽에서 `PORT` 값을 허용합니다. 기본 예시는 `PORT=8002`입니다.

## 비밀번호 접속과 서버 저장

접속 비밀번호 기본값은 `1222`입니다. 서버 환경변수 `STOCK8_PASSWORD`로 변경할 수 있습니다. 비밀번호 검증과 API 접근 제어는 서버에서 수행하며, 로그인은 HttpOnly 쿠키로 30일 유지됩니다.

종목·봉 주기·조회기간·선 정보는 `STOCK8_DATA_DIR` 아래 `dashboard.json`에 저장합니다. 기본 경로는 실행 폴더의 `data/`입니다. 로그인 서명 키도 같은 폴더의 `session-key`에 보관하므로 서버를 재시작해도 로그인과 저장 정보가 유지됩니다. 이 폴더는 Git에서 제외됩니다.

- 여러 컴퓨터에서 **같은 서버 주소**에 접속하면 같은 20칸과 선 정보를 불러옵니다. 다른 창의 변경은 약 5초마다 반영됩니다.
- 각 변경은 차트 칸·선 ID 단위로 병합하고, 파일은 임시 파일에서 원자적으로 교체합니다. 재전송한 변경은 중복 적용하지 않습니다.
- 기존 브라우저에 저장된 4개 종목은 서버가 아직 수정되지 않았을 때만 첫 페이지로 가져옵니다.
- 네트워크 오류 시 임시 변경을 브라우저에 유지하고 재시도합니다. 저장 연결 오류가 발생할 때만 헤더에 표시합니다.
- 배포·백업 시 **데이터 폴더를 보존**하세요. Docker를 사용할 경우 이 경로를 호스트 볼륨에 연결해야 합니다. 이 파일 저장 방식은 하나의 Node 서버 프로세스를 기준으로 합니다.

```bash
# 예: 코드 폴더 밖에 데이터를 보존하려는 경우
export STOCK8_DATA_DIR=/var/lib/stock8-7
export STOCK8_PASSWORD=1222
npm start
```

## 차트 조작

- 헤더는 지수와 버튼이 들어가면 한 줄을 우선 사용하고, 공간이 부족할 때만 지수 한 줄·버튼 한 줄로 최대 두 줄을 유지합니다. 지수 값과 등락폭은 정수로, 등락률은 소수점 두 자리로 표시합니다. 숫자와 등락률 칸은 고정 너비로 표시해 실시간 갱신 시 위치가 흔들리지 않습니다. 공간이 부족한 지수 줄은 좌우로 스크롤할 수 있습니다.
- 상단 **배치**: `2×2 → 1×3 → 3×1 → 2×2` 순환입니다. 가로 칸 수 × 세로 칸 수이며, 접속 기본값은 2×2입니다. 2×2는 차트 4개, 1×3은 세로로 3개, 3×1은 가로로 3개를 표시합니다. 세 차트 배치에서는 각 페이지의 앞 세 종목을 표시하며, 네 번째 종목은 저장된 채로 2×2 전환 시 다시 표시됩니다. 배치·창 크기가 바뀌면 각 차트를 조정해 스크롤 없이 한 화면 안에 맞춥니다.
- 차트 폭이 줄어도 보이는 봉의 범위는 유지하고 봉 사이 간격을 줄입니다. 조회기간이 400개라면 좁은 3×1 배치에서도 같은 400개를 표시합니다.
- 오른쪽 가격 축은 모든 차트가 같은 폭을 사용합니다. 기본 폭은 82px이며 더 긴 가격 표시가 필요하면 전체 차트의 폭을 함께 늘려, 가격 자릿수 때문에 캔들 영역의 폭이 달라지지 않도록 합니다.
- 같은 봉 주기와 조회 개수를 쓰는 차트는 실제 날짜·시각을 기준으로 시간축을 맞춥니다. 2×2는 같은 열의 위·아래 차트끼리, 1×3·3×1은 세 차트 모두 정렬합니다. 종목별로 빠진 시각은 빈칸으로 남겨 09:00 위치가 같아지며, 각 종목의 요청한 실제 봉들은 모두 표시합니다. 시간축 이동·확대도 함께 적용하고, 동일 시각의 세로 점선을 공유합니다. 가로·세로 마우스 점선은 이전보다 진한 회색입니다.
- 상단 **종목**: 5개 장 × 4개 종목을 한 창에서 검색·등록하고 저장합니다. 국내·미국 주식과 ETF, 코스피·코스닥·나스닥·S&P 500·다우 등 지수, 나스닥100 선물을 이름·코드·티커로 검색할 수 있습니다. 취소하면 기존 설정을 유지합니다. 종목 변경은 이 창에서만 가능합니다.
- 상단 **다음**: `1/5 → 2/5 → … → 5/5 → 1/5` 순환입니다. 페이지마다 독립된 4개 종목을 지정할 수 있습니다.
- 차트의 **선**: 버튼을 누르고 시작점부터 끝점까지 드래그합니다. 선을 클릭해 선택한 후 끝점을 드래그하면 위치를 수정할 수 있습니다. **굵기**는 1→2→3 순환, **선 삭제**와 Delete/Backspace는 선택한 선을 삭제합니다. 선택이 없을 때 선 삭제 버튼은 해당 종목의 모든 선을 삭제합니다. Esc는 그리기를 취소합니다.
- 선은 날짜·가격으로 저장되며 **종목별로 공유**됩니다. 같은 종목을 다른 페이지나 봉 주기에서 보더라도 같은 선 정보를 사용합니다. 로드한 기간 밖의 끝점은 숨기고 원래 날짜를 보존합니다.

- 종목명은 90px 폭의 읽기 전용 제목으로 표시하며 차트 제목에서 직접 종목을 바꿀 수 없습니다. 첫 줄은 종목명 옆에 분봉 버튼과 조회기간을, 다음 줄은 주가·등락률·이평선 범례·선 도구 순서로 표시합니다. 주가 글씨는 기본 16px이며, 좁은 차트에서는 글씨와 여백을 줄이고 도구를 줄바꿈해 버튼이 숨지 않도록 표시합니다.
- 이평선은 5·10·20·60·120·200기간이며, 색상은 stock5-8과 같습니다.
- 상단 **BB**: 네 차트의 볼린저밴드(20기간 평균 ± 2 표준편차)를 함께 표시/숨김합니다. 각 차트의 BB 범례로 개별 조절도 가능합니다.
- 상단 **주**: 네 차트를 주봉으로 바꾸고, 해제하면 각 차트의 이전 주기와 조회기간으로 돌아갑니다. 활성화 중에도 개별 봉 선택이 가능합니다.
- 상단 **삼선**: 선택한 1분·일·주 등 원본 봉의 종가로 3선전환도를 계산합니다. 같은 방향의 종가 돌파는 연장하고, 반대 방향은 최근 3개 전환선 몸통 범위를 엄격히 돌파할 때만 전환합니다. 동일 가격과 봉의 꼬리는 전환으로 세지 않습니다. 원본 이력을 최대 10,000개 요청하고 겹치는 조회 구간을 누적해 갱신 때 기준이 바뀌는 현상을 줄입니다. 중복 시각은 마지막 정정값을 사용하고 가격 자릿수 이하 오차를 제거합니다. 실제 시세 수신 실패 시 임의 예시 데이터로 삼선을 그리지 않습니다. 삼선전환도에서는 이동평균선 5·10·20·60·120·200과 볼린저밴드, MACD 배경을 모두 숨기고 범례는 유지합니다. 차트 간 세로 점선은 동기화하지 않고 마우스를 올린 차트에만 표시합니다. 해제하면 원본 캔들·이동평균선·BB의 개별 표시 설정·배경과 점선 동기화를 복원합니다.
- **Y축 범위**: 오른쪽 가격 눈금을 위아래로 드래그합니다. 더블클릭하면 자동 범위로 돌아갑니다. 실시간 갱신 중에는 수동 범위를 유지하고, 종목·주기 변경 시 자동 범위로 시작합니다.
- **종목코드·티커 검색**: `005930` 또는 `5930`은 삼성전자, `196170`은 알테오젠처럼 국내 코드를 실제 종목명·시장으로 인식합니다. 미국 주식은 `AAPL`, `aapl`, `AAPL.US`처럼 티커로 입력할 수 있고, 정확히 일치하는 티커를 우선 표시합니다.
- **ETF 검색**: 국내 ETF를 이름·브랜드명(KODEX, TIGER 등)·종목코드로 검색할 수 있습니다. ETF 목록은 12시간 캐시하고 갱신 실패 시 마지막 정상 목록을 사용합니다. 미국 ETF는 기존 미국 종목 검색 및 티커 직접 입력을 지원합니다.
- **나스닥 검색**: `나스닥`으로 종합지수·나스닥100 지수·선물·관련 ETF를 함께 검색합니다. `나스닥100 선물`, `나스닥선물`, `NQ`, `NQ=F`는 공급자의 최근월물 연결 심볼 `NQ=F`로 등록합니다. `QQQ`, `QQQM`, `TQQQ`, `SQQQ`와 국내 나스닥 ETF도 검색할 수 있습니다. 선물은 소수점 두 자리로 표시하고 NQ의 0.25 가격 단위를 유지합니다. 선물 시세 수신에 실패하면 임의 예시 차트로 대체하지 않고 오류를 표시합니다. 선물 시세는 공급처에 따라 지연될 수 있습니다.

## KIS 나스닥100 선물 실시간 시세

stock5-8의 서버 환경변수·토큰/접속키 캐시·웹소켓 연결 방식을 참조했습니다. stock5-8 코드는 수정하지 않습니다. 환경변수 우선순위는 실행 환경 → `.env.local` → `.env`입니다. 운영 서버의 기존 `KIS_APP_KEY`, `KIS_APP_SECRET`이 해외선물 조회 권한을 가진 경우 그대로 사용합니다. 해외선물용 키가 별도로 발급되어 있으면 서버 환경변수 `KIS_FUTURES_APP_KEY`, `KIS_FUTURES_APP_SECRET`을 **함께** 설정합니다. 키와 토큰은 브라우저에 전달하지 않습니다. 설정 파일을 변경한 뒤 앱 프로세스를 재시작해야 합니다.

- **사전 조건**: 해외선물 Open API 사용 등록과 CME 유료 실시간 시세 신청이 필요합니다. KIS 공식 예제에 따르면 HTS **[7936] 해외선물옵션 실시간 시세신청/조회**에서 신청하고, 신청 후 해당 키로 접근토큰을 발급해야 합니다. 권한 반영에는 최대 2시간이 걸릴 수 있습니다. [KIS 공식 실시간 시세 예제](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/overseas_futureoption/ccnl/ccnl.py)
- `NQ=F`를 선택하면 KIS 공식 `ffcode.mst`의 **NQ 최근월물**을 찾아 연결합니다. 마스터는 6시간 캐시합니다. 특정 월물은 `KIS_NQ_CONTRACT=NQZ26`처럼 지정할 수 있으며, 만기 이후에는 갱신하거나 비워 자동 선택을 사용해야 합니다. 실제 월물은 주가 옆 상태에 마우스를 올려 확인할 수 있습니다.
- **분봉·일봉·주봉·월봉 모두 KIS**에서 조회합니다. 연속조회 키로 이력을 가져오고, KIS 웹소켓 `HDFFF020`의 실제 체결로 최신 봉을 갱신합니다. 차트 화면에는 기존처럼 약 1초마다 반영됩니다. Yahoo 연결선물 이력과 서로 다른 월물을 섞지 않으며 삼선 이력도 월물별로 분리합니다.
- 웹소켓 체결이 실제로 들어오면 **실시간**, REST 조회만 성공하면 **KIS 시세**, 시각이 오래되면 **KIS 지연/마감**으로 표시합니다. 상태에 마우스를 올리면 시세 시각과 구독 실패 이유를 확인할 수 있습니다. 실시간 웹소켓에는 Node.js 22 이상이 필요하고, 방화벽에서 `ops.koreainvestment.com:21000`으로 나가는 연결이 가능해야 합니다.
- `KIS_WS_URL`은 포트 주소 또는 `/tryitout`까지 들어간 주소를 모두 지원합니다. 같은 키가 다른 앱에서 사용 중이라는 응답은 stock5-8처럼 5분간 재접속을 쉬고 표시합니다. 기존 앱의 연결을 끊지 않으며 필요한 경우 별도 해외선물 키를 사용하세요.
- 공급자의 수신·분봉 시각은 기본 `Asia/Seoul`로 해석합니다. 사용 중인 응답이 다른 시간대를 사용한다면 `KIS_FUTURES_TIME_ZONE`에 해당 IANA 시간대를 지정합니다. 실제 키로 검증할 때 최신 봉 시각을 함께 확인하세요.
- KIS가 설정된 상태에서 권한·조회에 실패하면 **수신 오류**를 표시합니다. 10분 지연 Yahoo나 임의 예시 데이터로 조용히 대체하지 않습니다. KIS 키가 없는 환경에서는 기존 Yahoo 지연 시세를 계속 사용합니다.
