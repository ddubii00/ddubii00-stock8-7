# stock8-7

4개 차트씩 총 10페이지(40칸)를 제공하는 KIS 우선 실시간 주식 대시보드입니다. 종목 설정과 추세선을 서버에 저장합니다.

## 실행

GitHub Codespaces 또는 로컬 환경변수에 아래 값을 설정한 뒤 실행합니다. 실제 키 값은 저장소에 커밋하지 않습니다.

```bash
export KIS_APP_KEY="..."
export KIS_APP_SECRET="..."
export KIS_BASE_URL="https://openapi.koreainvestment.com:9443"
export KIS_WS_URL="ws://ops.koreainvestment.com:21000"
export PORT=8002
npm start
```

KIS 환경변수가 없거나 KIS 응답이 실패하면 기존 공개 시세 데이터로 fallback합니다.

## GitHub Codespaces Secret 설정

KIS 키는 GitHub 저장소 파일에 넣지 말고 Codespaces Secret으로 설정합니다.

1. GitHub에서 `ddubii00/ddubii00-stock8-7` 저장소로 이동합니다.
2. `Settings` → `Secrets and variables` → `Codespaces`로 이동합니다.
3. `New repository secret` 또는 `New secret`을 눌러 아래 이름으로 추가합니다.
   - `KIS_APP_KEY`
   - `KIS_APP_SECRET`
   - `KIS_BASE_URL`
   - `KIS_WS_URL`
4. 값은 각각 KIS에서 발급받은 값을 넣습니다.
5. Codespace를 이미 켜둔 상태라면 재시작하거나 새 Codespace를 만듭니다.
6. Codespace 터미널에서 실행합니다.

```bash
npm start
```

Codespaces Secret은 터미널 환경변수로 자동 주입됩니다. GitHub Actions용 Secret만 만들면 Codespace 터미널에서 보이지 않을 수 있으니, 반드시 Codespaces Secret으로 설정합니다. `KIS_APP_KEY`, `KIS_APP_SECRET`은 Variables가 아니라 Secrets에 넣는 것을 권장합니다.

## 로컬 테스트

로컬에서는 `.env.example`을 참고해서 직접 환경변수를 export한 뒤 실행합니다. `.env` 파일을 만들 경우 `.gitignore`에 의해 커밋되지 않습니다.

## Oracle 서버 실행

Oracle Cloud VM에서는 Node.js 22 이상을 설치한 뒤 저장소를 받아 실행합니다. KIS 키는 저장소에 커밋하지 말고 서버의 `.env` 파일 또는 systemd 환경변수로만 설정합니다.

```bash
git clone https://github.com/ddubii00/ddubii00-stock8-7.git
cd ddubii00-stock8-7
npm install
cp .env.example .env
# .env에 KIS_APP_KEY, KIS_APP_SECRET, PORT를 설정
npm start
```

외부 접속이 필요하면 Oracle 보안 목록/NSG와 서버 방화벽에서 `PORT` 값을 허용합니다. 기본 예시는 `PORT=8002`입니다.

## 비밀번호 접속과 서버 저장

접속 비밀번호 기본값은 `1222`입니다. 서버 환경변수 `STOCK8_PASSWORD`로 변경할 수 있습니다. 비밀번호 검증과 API 접근 제어는 서버에서 수행하며, 로그인은 HttpOnly 쿠키로 30일 유지됩니다.

종목·봉 주기·조회기간·선 정보는 `STOCK8_DATA_DIR` 아래 `dashboard.json`에 저장합니다. 기본 경로는 실행 폴더의 `data/`입니다. 로그인 서명 키도 같은 폴더의 `session-key`에 보관하므로 서버를 재시작해도 로그인과 저장 정보가 유지됩니다. 이 폴더는 Git에서 제외됩니다.

- 여러 컴퓨터에서 **같은 서버 주소**에 접속하면 같은 40칸과 선 정보를 불러옵니다. 다른 창의 변경은 약 5초마다 반영됩니다.
- 각 변경은 차트 칸·선 ID 단위로 병합하고, 파일은 임시 파일에서 원자적으로 교체합니다. 재전송한 변경은 중복 적용하지 않습니다.
- 기존 브라우저에 저장된 4개 종목은 서버가 아직 수정되지 않았을 때만 첫 페이지로 가져옵니다.
- 네트워크 오류 시 임시 변경을 브라우저에 유지하고 재시도합니다. 저장 연결 오류가 발생할 때만 헤더에 표시합니다.
- 배포·백업 시 **데이터 폴더를 보존**하세요. Docker를 사용할 경우 이 경로를 호스트 볼륨에 연결해야 합니다. 이 파일 저장 방식은 하나의 Node 서버 프로세스를 기준으로 합니다.

```bash
# 예: 코드 폴더 밖에 데이터를 보존하려는 경우
export STOCK8_DATA_DIR=/var/lib/stock8-7
export STOCK8_PASSWORD=1222
npm start
```

## 차트 조작

- 헤더 지수는 코스피·코스닥·나스닥·달러/원 순서로 표시합니다. 지수 숫자 칸과 버튼 안팎 여백을 좁혀 한 줄을 우선 사용하고, 공간이 부족할 때만 지수 한 줄·버튼 한 줄로 최대 두 줄을 유지합니다. 지수 값과 등락폭은 정수로, 등락률은 소수점 두 자리로 표시합니다. 숫자와 등락률 칸은 고정 너비로 표시해 실시간 갱신 시 위치가 흔들리지 않습니다. 공간이 부족한 지수 줄은 좌우로 스크롤할 수 있습니다.
- 상단 **배치**: `2×2 → 1×3 → 3×1 → 1×1 → 2×1 → 1×2 → 4×4 → 한 종목 캔들·삼선 → 2×2`의 8단계 순환입니다. 가로 칸 수 × 세로 칸 수이며, 접속 기본값은 2×2입니다. 2×2는 첫 번째 왼쪽 위·두 번째 왼쪽 아래·세 번째 오른쪽 위·네 번째 오른쪽 아래로 차트 4개를 표시하며, 1×3은 세로로 3개, 3×1은 가로로 3개를 표시합니다. 세 차트 배치에서는 각 페이지의 앞 세 종목을 표시하며, 네 번째 종목은 저장된 채로 2×2 전환 시 다시 표시됩니다. 1×1은 현재 페이지의 첫 번째 종목만 화면 전체에 표시하며, 나머지 세 종목의 설정은 그대로 유지합니다. 2×1은 현재 페이지의 앞 두 종목을 가로로 표시하고, 1×2는 같은 두 종목을 위아래로 표시합니다. 배치·창 크기가 바뀌면 각 차트를 조정해 스크롤 없이 한 화면 안에 맞춥니다.
- 기존 4종목의 **2×2 배치는 유지**하고 별도로 추가한 **4×4 캔들·삼선 배치**는 총 4개 차트를 2열×2행으로 표시하는 비교 배치입니다. 각 장의 첫 번째 종목을 왼쪽 위 캔들·왼쪽 아래 삼선전환도로, 두 번째 종목을 오른쪽 위 캔들·오른쪽 아래 삼선전환도로 표시합니다. 세 번째·네 번째 저장 종목은 다른 배치에서 그대로 사용합니다. 이 모드에서는 헤더 **삼선** 버튼이 비활성화되며, 아래 삼선전환도에는 이평선·BB·MACD 배경을 적용하지 않습니다. 캔들 또는 삼선에서 가리킨 봉의 시각을 나머지 모든 차트와 공유합니다. 캔들에는 해당 시간대의 봉에, 삼선에는 그 시각 이전의 가장 최근 선에 세로 점선을 표시합니다(10:03 캔들 → 최근 삼선 09:50). 다른 차트의 표시 범위는 바꾸지 않습니다. 이 배치의 BB 기본값은 꺼짐이며, 헤더 BB 버튼으로 캔들차트에서 켤 수 있습니다. 기존 배치의 BB 선택은 별도로 유지됩니다. 각 종목의 위·아래 차트는 같은 저장 종목·봉 주기·봉 개수를 사용합니다.
- 맨 마지막 **한 종목 캔들·삼선 배치**는 각 장에 저장된 첫 번째 종목만 위 캔들·아래 삼선으로 표시합니다. 4×4 비교 배치를 유지하면서 추가한 한 열·두 행 배치이며, 두 차트를 한 화면에 맞춥니다. 위 캔들의 MACD 교차 화살표와 아래 삼선의 대응 시점 점선 연동을 적용하고 헤더 삼선 버튼은 비활성화합니다. 이 배치도 BB는 기본 꺼짐이며 다른 배치의 BB 선택과 분리합니다.
- 헤더의 **표시** 버튼은 기본 켜짐입니다. 끄면 캔들차트의 MACD 골든·데드크로스 화살표를 모두 숨기고 다시 누르면 표시합니다. 같은 탭에서는 장·배치를 바꿔도 선택을 유지하며, MACD 배경은 그대로 표시합니다.
- 4×4 배치의 **왼쪽 위·오른쪽 위 캔들차트**에는 MACD(12·26)와 시그널(9)의 골든크로스를 캔들 아래 작은 빨간 위 화살표로, 데드크로스를 캔들 위 작은 파란 아래 화살표로 표시합니다. 충분한 이전 봉으로 계산하며, 진행 중인 봉의 가격이 바뀌면 화살표도 갱신됩니다.
- 차트 폭이 줄어도 보이는 봉의 범위는 유지하고 봉 사이 간격을 줄입니다. 조회기간이 400개라면 좁은 3×1 배치에서도 같은 400개를 표시합니다.
- 오른쪽 가격 축은 모든 차트가 같은 폭을 사용합니다. 기본 폭은 82px이며 더 긴 가격 표시가 필요하면 전체 차트의 폭을 함께 늘려, 가격 자릿수 때문에 캔들 영역의 폭이 달라지지 않도록 합니다.
- 각 차트의 봉 주기·봉 개수·표시 범위·시간축 이동과 확대는 독립적입니다. 400을 입력하면 해당 차트의 실제 최신 400개 봉을 표시하며, 장후 모드에서도 임의로 620개로 늘리지 않습니다. 분봉은 주기·봉 개수가 달라도 날짜·시각을 기준으로 세로 점선을 공유합니다. 예를 들어 위 1분봉의 14:30 또는 14:31을 가리키면 아래 5분봉의 14:30 봉에 표시합니다. 해당 봉이 아래 차트의 현재 표시 범위에 없으면 점선을 숨기며, 표시 범위를 자동 이동하지 않습니다. 일·주·월봉에는 해당 거래소 날짜·주·월에 해당하는 봉을 표시합니다. 2×2의 좌우 열을 포함해 화면에 보이는 모든 차트가 점선을 공유하며 다른 차트의 표시 범위를 바꾸지 않습니다. 가로·세로 마우스 점선은 이전보다 진한 회색입니다.
- 상단 **종목**: 10개 장 × 4개 종목을 한 창에서 검색·등록하고 저장합니다. 국내·미국 주식과 ETF, 코스피·코스닥·나스닥·S&P 500·다우 등 지수, 나스닥100 선물을 이름·코드·티커로 검색할 수 있습니다. 취소하면 기존 설정을 유지합니다. 종목 변경은 이 창에서만 가능합니다.
- 상단 **이전·다음**: `1/10 ↔ 2/10 ↔ … ↔ 10/10`으로 이동하며 양 끝에서 순환합니다. 다음 오른쪽의 현재 장/전체 장 표시는 유지합니다. 기존 5장 저장 파일은 종목·주기·봉 개수와 선 정보를 보존한 채 10장으로 자동 확장합니다. 페이지마다 독립된 4개 종목을 지정할 수 있습니다.
- 차트의 **선**: 버튼을 누르고 시작점부터 끝점까지 드래그합니다. 선을 클릭해 선택한 후 끝점을 드래그하면 위치를 수정할 수 있습니다. **굵기**는 1→2→3 순환, **선 삭제**와 Delete/Backspace는 선택한 선을 삭제합니다. 선택이 없을 때 선 삭제 버튼은 해당 종목의 모든 선을 삭제합니다. Esc는 그리기를 취소합니다.
- 선은 날짜·가격으로 저장되며 **종목별로 공유**됩니다. 같은 종목을 다른 페이지나 봉 주기에서 보더라도 같은 선 정보를 사용합니다. 로드한 기간 밖의 끝점은 숨기고 원래 날짜를 보존합니다.

- 종목명은 좁은 읽기 전용 제목으로 표시하며 차트 제목에서 직접 종목을 바꿀 수 없습니다. 첫 줄은 종목명·1분~월 버튼·봉 개수 입력창을 줄바꿈 없이 표시하고, 조회기간 문구는 표시하지 않습니다. 좁은 화면에서는 버튼과 글씨를 줄이고 부족한 경우 첫 줄을 가로 스크롤할 수 있습니다. 다음 줄은 주가·등락률·이평선 범례·선 도구 순서로 표시합니다. 주가 글씨는 기본 16px이며, 좁은 차트에서는 글씨와 여백을 줄이고 도구를 줄바꿈해 버튼이 숨지 않도록 표시합니다.
- 이평선은 5·10·20·60·120·200기간이며, 색상은 stock5-8과 같습니다.
- 상단 **BB**: 네 차트의 볼린저밴드(20기간 평균 ± 2 표준편차)를 함께 표시/숨김합니다. 각 차트의 BB 범례로 개별 조절도 가능합니다.
- 상단 **주**: 네 차트를 주봉으로 바꾸고, 해제하면 각 차트의 이전 주기와 조회기간으로 돌아갑니다. 활성화 중에도 개별 봉 선택이 가능합니다.
- 상단 **삼선**: 선택한 1분·일·주 등 원본 봉의 종가로 3선전환도를 계산합니다. 같은 방향의 종가 돌파는 연장하고, 반대 방향은 최근 3개 전환선 몸통 범위를 엄격히 돌파할 때만 전환합니다. 동일 가격과 봉의 꼬리는 전환으로 세지 않습니다. 원본 이력을 최대 10,000개 요청하고 겹치는 조회 구간을 누적해 갱신 때 기준이 바뀌는 현상을 줄입니다. 중복 시각은 마지막 정정값을 사용하고 가격 자릿수 이하 오차를 제거합니다. 실제 시세 수신 실패 시 임의 예시 데이터로 삼선을 그리지 않습니다. 삼선전환도에서는 이동평균선 5·10·20·60·120·200과 볼린저밴드, MACD 배경을 모두 숨기고 범례는 유지합니다. 삼선에 마우스를 올려도 가리킨 봉의 시각을 다른 모든 차트의 세로 점선에 전달합니다. 전체 삼선 모드에서도 연동하며, 각 삼선의 그 시각 이전 가장 최근 선에 표시합니다. 해제하면 원본 캔들·이동평균선·BB의 개별 표시 설정·배경을 복원합니다.
- 최근가격 눈금표의 배경색은 마지막으로 표시한 봉의 색을 따릅니다(상승 봉 빨강·하락 봉 파랑). 삼선전환도는 마지막 삼선 봉을 기준으로 하며 최근가격 수평선을 숨깁니다. 삼선의 가격 박스만 약간 크게 표시하고 마지막 삼선 봉의 색이 직전 삼선 봉과 달라졌으면 박스 바로 위에 ‘전환’을 표시합니다. 캔들차트는 마지막 캔들 봉을 기준으로 하고 최근가격 수평 점선을 유지합니다.
- 마우스 시세 팝업은 캔들을 가리지 않도록 오른쪽 가격 눈금 영역의 봉 주기 버튼 줄 높이에 작게 고정하고 시가·종가·등락률만 표시합니다. 팝업의 날짜·시각은 생략합니다.
- **미국 주식·ETF 등락폭/등락률**: 차트 주기나 조회기간과 관계없이 미국 현지(`America/New_York`) 기준 직전 거래일의 정규장 종가로 계산합니다. 프리마켓·장후 가격도 같은 기준을 사용하며, 월요일 프리마켓은 금요일 정규장 종가와 비교합니다. 정규장 전용 일봉의 실제 거래일을 조회하므로 휴일·주말과 서머타임을 반영합니다. Yahoo의 조회기간 시작 기준가나 직전 분봉·주봉·월봉을 비교 기준으로 쓰지 않습니다. KIS 현재가의 전일 종가는 `base`이며 `pvol`은 전일 거래량입니다. 등락률에 마우스를 올리면 기준 날짜·종가와 등락폭을 확인할 수 있습니다.
- **코스피·코스닥 분봉**: 네이버 지수 당일 차트의 실제 1분 OHLC를 과거 분봉에 합칩니다. 지연된 Yahoo 이력에 최신 현재가만 붙어 최근 약 20분이 비는 구간을 보완합니다. 캔들에는 모든 수신 분봉을 표시하고, 삼선전환도만 그 원본에서 전환 조건을 적용합니다. KIS 지수 분봉이 있으면 기존처럼 우선 적용하며, 수신하지 못한 분봉을 임의로 만들지 않습니다.
- **KRX 분봉**: 전일을 포함해 20:00까지의 실제 장후 체결을 표시합니다. 09:00~15:19 접속매매, 15:20~15:29 종가 동시호가 중에는 임의 봉을 만들지 않으며, 15:31~15:32에 전달된 종가도 15:30 봉으로 정리합니다. 16:00~20:00 장후 봉은 별도로 유지해 정규장 종가에 덮어쓰지 않습니다. KIS `주식일별분봉조회(FHKST03010230)`를 날짜·시간으로 연속 조회하며, 실전 조회 불가 시 당일 KIS 및 공개 분봉으로 보완합니다. 공개 분봉도 당일 15:30 제한을 없애 이전 거래일 장후 이력을 함께 받습니다. 거래가 없는 시간이나 휴장일의 봉을 임의로 채우지 않고, 지수는 기존 정규장 범위를 유지합니다. [KRX 애프터마켓 및 차트 변경 안내](https://www.kiwoom.com/e/m/home/event/VEvent20260093View), [KIS 일별분봉 공식 사양](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/domestic_stock/inquire_time_dailychartprice/inquire_time_dailychartprice.py)
- **Y축 범위**: 오른쪽 가격 눈금을 위아래로 드래그합니다. 더블클릭하면 자동 범위로 돌아갑니다. 실시간 갱신 중에는 수동 범위를 유지하고, 종목·주기 변경 시 자동 범위로 시작합니다.
- **종목코드·티커 검색**: `005930` 또는 `5930`은 삼성전자, `196170`은 알테오젠처럼 국내 코드를 실제 종목명·시장으로 인식합니다. 미국 주식은 `AAPL`, `aapl`, `AAPL.US`처럼 티커로 입력할 수 있고, 정확히 일치하는 티커를 우선 표시합니다.
- **ETF 검색**: 국내 ETF를 이름·브랜드명(KODEX, TIGER 등)·종목코드로 검색할 수 있습니다. ETF 목록은 12시간 캐시하고 갱신 실패 시 마지막 정상 목록을 사용합니다. 미국 ETF는 기존 미국 종목 검색 및 티커 직접 입력을 지원합니다.
- **검색 응답**: 주요 종목·별칭·저장된 종목은 브라우저에서 즉시 표시하고, 서버는 외부 검색이 모두 끝나기를 기다리지 않고 확보한 결과부터 반환합니다. 추가 결과는 선택 목록에 이어서 반영합니다. 같은 검색은 5분 캐시하고 진행 중인 조회도 공유합니다. 국내 전체 목록은 KIS 공식 코스피·코스닥 파일 두 개로 가져오며 API 키가 필요하지 않습니다. 파일 조회 실패 시에만 기존 웹 목록을 최대 4개씩 읽습니다. 목록은 `STOCK8_DATA_DIR/search-catalog.json`에 저장해 서버 재시작 때 재사용합니다. 갱신 실패 시 마지막 목록을 유지하고 재시도를 잠시 쉽니다. [공식 코스피 형식](https://github.com/koreainvestment/open-trading-api/blob/main/stocks_info/kis_kospi_code_mst.py), [코스닥 형식](https://github.com/koreainvestment/open-trading-api/blob/main/stocks_info/kis_kosdaq_code_mst.py)
- **나스닥 검색**: `나스닥`으로 종합지수·나스닥100 지수·선물·관련 ETF를 함께 검색합니다. `나스닥100 선물`, `나스닥선물`, `NQ`, `NQ=F`는 공급자의 최근월물 연결 심볼 `NQ=F`로 등록합니다. `QQQ`, `QQQM`, `TQQQ`, `SQQQ`와 국내 나스닥 ETF도 검색할 수 있습니다. 선물은 소수점 두 자리로 표시하고 NQ의 0.25 가격 단위를 유지합니다. 선물 시세 수신에 실패하면 임의 예시 차트로 대체하지 않고 오류를 표시합니다. 선물 시세는 공급처에 따라 지연될 수 있습니다.

## KIS 나스닥100 선물 실시간 시세

stock5-8의 서버 환경변수·토큰/접속키 캐시·웹소켓 연결 방식을 참조했습니다. stock5-8 코드는 수정하지 않습니다. 환경변수 우선순위는 실행 환경 → `.env.local` → `.env`입니다. 운영 서버의 기존 `KIS_APP_KEY`, `KIS_APP_SECRET`이 해외선물 조회 권한을 가진 경우 그대로 사용합니다. 해외선물용 키가 별도로 발급되어 있으면 서버 환경변수 `KIS_FUTURES_APP_KEY`, `KIS_FUTURES_APP_SECRET`을 **함께** 설정합니다. 키와 토큰은 브라우저에 전달하지 않습니다. 설정 파일을 변경한 뒤 앱 프로세스를 재시작해야 합니다.

- **사전 조건**: 해외선물 Open API 사용 등록과 CME 유료 실시간 시세 신청이 필요합니다. KIS 공식 예제에 따르면 HTS **[7936] 해외선물옵션 실시간 시세신청/조회**에서 신청하고, 신청 후 해당 키로 접근토큰을 발급해야 합니다. 권한 반영에는 최대 2시간이 걸릴 수 있습니다. [KIS 공식 실시간 시세 예제](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/overseas_futureoption/ccnl/ccnl.py)
- `NQ=F`를 선택하면 KIS 공식 `ffcode.mst`의 **NQ 최근월물**을 찾아 연결합니다. 사용하는 동안 5분마다 목록을 다시 확인하며, KIS 최근월물 표시가 바뀌면 다음 조회부터 새 월물의 시세·차트·실시간 구독으로 전환합니다. 이전 월물의 실시간 봉과 삼선 이력은 새 월물에 섞지 않으며 가격 범위도 새로 맞춥니다. 특정 월물은 `KIS_NQ_CONTRACT=NQZ26`처럼 지정할 수 있지만 이 경우 자동 교체하지 않으므로, 자동 교체를 사용하려면 이 값을 비우고 앱을 재시작합니다. 주가 옆 상태에 마우스를 올리면 실제 월물과 자동/고정 모드를 확인할 수 있습니다. 이 기능은 시세 차트의 월물 전환이며 보유 포지션을 매매하거나 롤오버 주문을 내지 않습니다.
- **분봉·일봉·주봉·월봉 모두 KIS**에서 조회합니다. 연속조회 키로 이력을 가져오고, KIS 웹소켓 `HDFFF020`의 실제 체결로 최신 봉을 갱신합니다. 차트 화면에는 기존처럼 약 1초마다 반영됩니다. Yahoo 연결선물 이력과 서로 다른 월물을 섞지 않으며 삼선 이력도 월물별로 분리합니다.
- 웹소켓 체결이 실제로 들어오면 **실시간**, REST 조회만 성공하면 **KIS 시세**, 시각이 오래되면 **KIS 지연/마감**으로 표시합니다. 상태에 마우스를 올리면 시세 시각과 구독 실패 이유를 확인할 수 있습니다. 실시간 웹소켓에는 Node.js 22 이상이 필요하고, 방화벽에서 `ops.koreainvestment.com:21000`으로 나가는 연결이 가능해야 합니다.
- `KIS_WS_URL`은 포트 주소 또는 `/tryitout`까지 들어간 주소를 모두 지원합니다. 같은 키가 다른 앱에서 사용 중이라는 응답은 stock5-8처럼 5분간 재접속을 쉬고 표시합니다. 기존 앱의 연결을 끊지 않으며 필요한 경우 별도 해외선물 키를 사용하세요.
- 공급자의 수신·분봉 시각은 기본 `Asia/Seoul`로 해석합니다. 사용 중인 응답이 다른 시간대를 사용한다면 `KIS_FUTURES_TIME_ZONE`에 해당 IANA 시간대를 지정합니다. 실제 키로 검증할 때 최신 봉 시각을 함께 확인하세요.
- KIS가 설정된 상태에서 권한·조회에 실패하면 **수신 오류**를 표시합니다. 10분 지연 Yahoo나 임의 예시 데이터로 조용히 대체하지 않습니다. KIS 키가 없는 환경에서는 기존 Yahoo 지연 시세를 계속 사용합니다.
- **수신 오류 진단**: 가격 오른쪽 ‘수신 오류’에 마우스를 올리거나 차트 하단 문구를 보면 요청 월물, API TR, HTTP 상태 및 KIS의 `msg_cd`·`msg1`을 확인할 수 있습니다. HTTP 500만으로 CME 권한 문제라고 단정하지 않습니다. HTTP 오류 응답의 상세 내용도 보존하되 키·토큰은 가립니다. 일반 오류 페이지 HTML은 브라우저에 전달하지 않습니다. 업데이트 후 앱 프로세스를 재시작해야 새 진단 문구가 표시됩니다.
